# Куда смотреть за MIDI

Указатели, не выгрузка. И базовый корпус, и дополнительный под гипотезу команда
собирает сама. Не кладите сюда файлы, на которых уже закрыли чужую гипотезу.

Перед скачиванием запишите в свою таблицу: URL, композитор, название, **лицензия
файла**, дата проверки. Строка без лицензии в `src/catalog.py` отбрасывается.

## Подходящие отправные точки

| Источник | Что там | Лицензия (проверять по карточке) | Зачем |
|---|---|---|---|
| [Mutopia Project](https://www.mutopiaproject.org/) | классика, есть MIDI + LilyPond | чаще CC-BY-SA разных версий или PD; смотрите карточку пьесы | ноктюрны Шопена и Фильда, другие жанры |
| [music21 corpus](https://web.mit.edu/music21/doc/about/referenceCorpus.html) | хоралы Баха, ещё Bach, Monteverdi, Palestrina | произведения PD; сам music21 — BSD | собрать **базу**, взять другой жанр той же эпохи |
| [KernScores](http://kern.humdrum.org/) | символические партитуры, в т.ч. романтики | обычно PD на произведение; проверяйте notice | другая фактура / эпоха |
| [piano-midi.de](http://www.piano-midi.de/copy.htm) | фортепианные MIDI Бернда Крюгера | **CC-BY-SA** (указано на странице Copyright) | часть HTTP-клиентов его не видит (SSRF); не блокируйтесь на нём |
| [MAESTRO MIDI-only](https://magenta.tensorflow.org/datasets/maestro) | zip ~58 МБ, 1276 фортепианных MIDI | **CC BY-NC-SA 4.0** | основной bulk-источник; аудио (~100 ГБ) не качать |

Индекс MAESTRO без готового доп. корпуса. Zip в git не кладите.

```bash
python tools/download_maestro.py
```

Скрипт **не качает заново**: ищет zip в `MAESTRO_ZIP`, `raw/`, соседнем `cache/`
или `Desktop/altair/cache/`, распаковывает CSV.
CSV — `data/maestro_index.csv`: композитор, название, путь внутри архива. Свои
MIDI команда извлекает **сама** под гипотезу, не весь zip. Zip в git не входит.

Поиск по Mutopia: `nocturne`, `mazurka`, `chorale`, `invention` — сначала
карточка лицензии, потом `.mid`.

## Осторожно

- **Lakh MIDI Dataset.** Каталог Раффеля — CC-BY 4.0. Сами MIDI собраны из
  интернета, у части права неясны. Не коммитьте Lakh целиком и не пишите в
  README, что «все файлы PD». Если берёте — фильтр по композиторам, у которых
  произведение точно в общественном достоянии, плюс явная оговорка.
- **IMSLP.** Произведение может быть PD, а конкретный скан / MIDI — нет.
  Без лицензии именно этого файла в корпус не класть.
- **Wiki-подобные MIDI-страницы и «скачать 10000 MIDI».** Обычно без лицензии.
- **MAESTRO.** NC и SA наследуют дообученный чекпоинт. Для школьного
  некоммерческого хакатона NC обычно приемлемо; выкладывать чекпоинт на
  публичный GitHub без оговорки — уже вопрос. Базу поэтому лучше собирать
  из PD, чтобы стартовый чекпоинт не тащил NC.

## Как класть свой корпус

```text
data/base_corpus/*.mid           # то, на чём получаете первую генерацию
data/extra_corpus/*.mid          # корпус под гипотезу; только латиница в именах
data/extra_metadata.csv          # file, work_id, composer, title, license, source
```

Один `work_id` на одно произведение, даже если нарезали 10 окон. Иначе split
по пьесе теряет смысл. Модель и скрипт дообучения — ваши.
