# Указатели на открытые наборы

Скачивайте сами, лицензию сверяйте по официальной странице. Архивы в этот репозиторий не кладите.

- CVC-MUSCIMA (рукопись, писцы, снятие стана): http://pages.cvc.uab.es/cvcmuscima/index_database.html — CC BY-NC-SA 4.0
- MUSCIMA++ (разметка staff-level): https://ufal.mff.cuni.cz/muscima/ — CC BY-NC-SA 4.0; картинки — из CVC-MUSCIMA отдельно
- HOMUS (изолированные рукописные символы): http://grfia.dlsi.ua.es/homus/ — лицензию уточнить
- PrIMuS (печатные монофонические инципиты): https://grfia.dlsi.ua.es/primus/ — лицензию уточнить
- DeepScores (синтетическая печать): https://tuggeluk.github.io/deepscores/ — V2 CC BY 4.0, очень большой объём
- Зеркала zip: https://github.com/apacha/OMR-Datasets

Разбиение train/val/test — по писцу или по источнику, не по случайной странице.
