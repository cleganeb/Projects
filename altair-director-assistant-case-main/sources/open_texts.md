# Откуда брать тексты

Только общественное достояние или явная открытая лицензия (PD, CC0, CC BY).
Современную драматургию и сайты без лицензии не брать.

## Русские пьесы

Проверенные указатели (страницы живы на 17.09.2026):

- Чехов, «Чайка» — Викитека, шаблон `PD-old-70`:
  https://ru.wikisource.org/wiki/Чайка_(Чехов)
  Действия лежат отдельными страницами (`/Действие первое` … `/Действие четвёртое`).
- Островский, «Гроза» — Викитека, `PD-old-70`:
  https://ru.wikisource.org/wiki/Гроза_(Островский)/ПСС_1950_(СО)
- Другие пьесы Чехова, Островского, Грибоедова, Гоголя на Викитеке — смотрите поле
  «Лицензия» в карточке. Нет поля — не берём.

lib.ru / ilibrary.ru часто содержат те же PD-тексты, но лицензия *сборника* может быть
отдельной. Для отчёта надёжнее Викитека или Gutenberg.

## Английские пьесы

- Shakespeare, *Hamlet*, Project Gutenberg № 1524 (Public domain in the USA):
  https://www.gutenberg.org/ebooks/1524
  На этой площадке тот же файл лежит локально, если `web_fetch` до Gutenberg/Викитеки не доходит (SSRF на 127.98.*). Команды качают сами, готовый `hamlet.txt` в этот репозиторий не кладут.
- Чехов, *The Cherry Orchard* — внутри сборника *Plays by Anton Chekhov, Second Series*, Gutenberg № 7986:
  https://www.gutenberg.org/ebooks/7986
  Переводчик Julius West, ум. 1918. Нужно **вырезать только эту пьесу**, не тащить в корпус «Трёх сестёр» из того же тома.
- Чехов, *The Sea-Gull*, Gutenberg № 1754:
  https://www.gutenberg.org/ebooks/1754
  Это тоже перевод: проверяйте смерть переводчика, не только Чехова.
- Ostrovsky, *The Storm*, Gutenberg № 7991 (перевод Constance Garnett, ум. 1946):
  https://www.gutenberg.org/ebooks/7991

Folger Shakespeare Library публикует тексты, но лицензия у них своя — читайте страницу
конкретного издания, не копируйте «на всякий случай».

## Чего не делать

- Не выкачивать современные пьесы с театральных сайтов.
- Не брать фрагменты из закрытых учебных хрестоматий «для школы».
- Не подмешивать в корпус текст, лицензию которого не можете назвать в одну строку.

Имена файлов — латиницей (`chaika.txt`, не `Чайка.txt`): на Windows часть библиотек
не открывает пути с кириллицей. CSV, если заведёте, — UTF-8 с BOM.
