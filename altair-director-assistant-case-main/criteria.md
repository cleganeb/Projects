# Критерии

Сжато по ТЗ. Первоисточник — PDF.

## Минимум (должно работать на открытой пьесе)

- принимает художественный текст;
- делит его на сцены;
- выделяет персонажей и участие по сценам;
- карточка сцены: события, цели — с опорой на цитату;
- можно открыть отдельную сцену;
- хотя бы один вариант сценического решения;
- вопросы по *сохранённому* проекту (после правки сцены ответ меняется), не новый чат с нуля.

Интерфейс: Streamlit или Gradio достаточно. Большая облачная модель не требуется и
противоречит постановке, если ею подменяют всю работу.

## Сильный результат

- связи сцен и персонажей, линия героя через пьесу;
- литературный и пластический варианты, несколько альтернатив;
- учёт ограничений постановки;
- режиссёр правит части проекта, решения сохраняются;
- факты текста отделены от интерпретаций;
- устойчиво на компактной модели / узком конвейере.

## Как проверять, не подглядывая в чужое решение

1. Возьмите пьесу, которой не было в чужом демо (вторая PD-пьеса с Викитеки).
2. Найдите явление, где по ремарке кто-то входит. Персонаж должен появиться в списке.
3. Переименуйте сцену, задайте тот же вопрос ещё раз. Если название откатилось — проекта нет.
4. Спросите про событие из *другой* пьесы. Система не должна уверенно его «вспомнить».
5. Прочитайте предложенную мизансцену: все названные люди есть в карточке? Есть цитата?
